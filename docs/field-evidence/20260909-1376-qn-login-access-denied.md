# 1.1.1376 更新后恢复现场结论

现场版本：1.1.1376，Windows Server 2022。

已确认：

- Bot 新版本健康启动，41010 首次绑定失败后可由现有自恢复重新监听；
- 自动更新恢复在 25 秒后主动结束原千牛并启动新千牛；
- 新千牛停在已保存账号登录页；
- UIA 和屏幕坐标输入均返回 `Win32Exception: 拒绝访问`；
- 被重启后注入长时间无法恢复，所有依赖 QN/CDP 的 Bot 能力不可用。

因此自动更新不再把 `injection=未连接` 直接升级为千牛进程重启。更新后的唯一恢复权威只负责 Bot 41010 监听与等待原 WebView 注入重连。千牛进程和登录态必须被保留。
