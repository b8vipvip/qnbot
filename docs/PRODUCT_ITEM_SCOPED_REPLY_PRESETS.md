# 商品链接专属固定话术（知识中心 V2）

适用场景：商品链接前置回复优先于普通知识库匹配。**不能仅修改知识库答案或历史 Bot 来源标签**来改变此类首轮回复。

## 为一件商品配置精确回复

1. 打开 `知识中心 V2 → Bot回复管理 → 内置固定话术`，确认当前店铺正确。
2. 点击「新增话术」，填写名称，例如「电视音乐会员商品专属回复」。
3. 在「触发条件」输入 `商品ID:1234567890123`（换成实际淘宝/天猫数字商品 ID，不要输入整段 URL），在「话术内容」输入人工核实的商品事实。
4. 勾选「启用此话术」，点击「保存话术」。
5. 其他通用「买家消息包含商品链接」话术可以保留启用：本商品优先使用专属话术；其他商品继续走通用随机话术。
6. 在「测试台 → 模拟对话」启用商品链接场景，粘贴对应商品的完整商品链接（带 `id=1234567890123` 查询参数；替换为实际 ID）验证预览。模拟对话不会真正向买家发送消息。真实发送需新买家消息与卖家回显核对。

注意：
- 商品 ID 仅从商品消息的权威 `itemId` 或可识别的淘宝/天猫商品 URL 的 `id` 参数提取；不从任意数字猜测。
- 不能识别数字商品 ID 的短链接仍使用通用话术。未知商品不会误用其他商品的专属答案。
- 每个店铺同一商品只能有一条**启用**的专属固定话术，避免歧义；变更只影响保存后的新消息。
- 本功能控制商品链接触发时的**固定话术**优先级，不意味着所有知识库问题都会绕过安全/工作流门禁。
