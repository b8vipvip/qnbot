# Bot 更新后的千牛会话恢复契约

自动更新只替换并重启 Bot，不应关闭、结束、重新启动或操作已经登录的千牛进程。

更新后的恢复顺序：

1. 新 Bot 完成版本绑定健康确认。
2. 恢复本地 `127.0.0.1:41010` WebSocket 监听。
3. 等待原千牛 WebView 中已经注入的脚本重新连接新 Bot。
4. 短宽限期后仍未连接时，继续在保护窗口中等待，而不是重启千牛。
5. 保护窗口结束后仍未连接，进入低频非破坏性恢复；只允许修复 Bot 监听并等待注入连接。

自动更新恢复路径禁止：

- 关闭或 Kill 千牛进程；
- 启动新的千牛进程；
- 点击千牛登录、账号选择、接待入口或历史消息确认；
- 读取、填写或切换账号密码。

原因：现场 Windows Server 2022 已证明跨进程 UIA/鼠标输入可能返回“拒绝访问”。更重要的是，杀掉原本已登录的千牛会把一个可恢复的 Bot↔WebView 连接问题扩大成登录态丢失，导致所有依赖注入/CDP 的功能长时间不可用。
